# 3D models (not included)

The character and hammer models are third-party downloads and are not redistributed in this repository.

1. From mixamo.com (free Adobe account) download the character **Knight D Pelegrini** with the animations **Breathing Idle** and **Walking**, each as *FBX for Unity, With Skin*.
2. Put the files in this folder. The scene builder finds them by name: "idle" and "walk" in the animation file names, "character" in a separate character file (optional; otherwise the idle file is used), "hammer" in a hammer model.
3. In Unity run **Project 9 → Rebuild Game Scene**.

Without them the game works the same, with a capsule as the player and built-in hammers.
